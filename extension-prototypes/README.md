# extension-prototypes/ — прототипы расширения под дизайн сайта

> **Для агентов, работающих в этом репозитории:** это **одноразовые дизайн-прототипы**
> для `client-extension/`. Это статические HTML/CSS/JS-макеты с **ненастоящими данными**:
> они не обращаются к серверу, не используют API расширений, не собираются и не
> участвуют в рантайме. Ничто вне этой папки на них не ссылается. Не «чините»,
> не рефакторите и не подключайте их к приложению. Не удаляйте файлы по одному.
> Когда владелец выберет вариант, он будет перенесён в `client-extension/`, а папка
> удалится целиком.

## Зачем это

Веб-интерфейс сервера (`server/public/`) уже переведён на новый дизайн — светлая
админ-панель «Панель»: ноль скруглений, синий акцент `#2563eb`, системные шрифты,
карточки в 1px-рамках, пилюли статусов, полосы прогресса. Расширение
(`client-extension/`) осталось в старом тёмном фиолетовом виде.

Здесь лежат **три кликабельных прототипа попапа расширения** в дизайне сайта. Они не
отличаются друг от друга «обёрткой»: у них **разная логика**, чтобы выбор был настоящий.

> **Итог выбора (для истории):** владелец выбрал вариант **01 «Рескин»** и попросил три
> правки — ручной выбор серий чипами, кнопку «Только субтитры» и сворачиваемую очередь.
> Всё это уже перенесено в `client-extension/` (версия 0.7.0) вместе с починкой
> подвисаний при вводе адреса сервера. Варианты `02` и `03` остаются здесь только как
> история обсуждения, переносить их не нужно (третий — «Автопилот» — владелец
> использовать не будет).

| Папка | Название | Насколько далеко от текущего расширения |
|---|---|---|
| `01-reskin` | Рескин | **Только вид.** Состав, порядок и логика — как в текущем попапе. |
| `02-wizard` | Мастер | **Другая компоновка и сценарий:** пошаговый мастер вместо простыни, выбор серий чипами, отдельный экран очереди с фильтрами. |
| `03-autopilot` | Автопилот | **Другая парадигма:** попапа нет вообще. Панель живёт поверх страницы, качает умолчаниями в один клик, умеет сама ставить сезон и следить за новыми сериями. |

Прототипы **автономные**: чистый HTML/CSS/JS без зависимостей, без сборки, без бэкенда.
Данные — захардкоженный мок, «скачивание» живёт симуляцией (прогресс реально растёт
раз в секунду). Интерфейс русский, как в расширении.

Общее у всех трёх: палитра и компоненты дизайна сайта, ноль скруглений, системные
шрифты, отмена/удаление подтверждаются вторым кликом, тосты, виджет сервера
(свободное место, папка, статус связи).

## Как открыть

Вариант 1 — просто открыть страницу в браузере (двойной клик по файлу, всё работает):

- `index.html` — галерея со ссылками на все три варианта.

Вариант 2 — через любой статический сервер:

```bash
cd extension-prototypes
python3 -m http.server 9100
# → http://localhost:9100/
```

## Состав

| Файл | Что это |
|---|---|
| `index.html` | Галерея для выбора между прототипами |
| `SPEC.md` | Общее ТЗ: мок-данные, симуляция, и что именно отличается в каждом варианте |
| `01-reskin/` | Попап как сейчас, но в дизайне сайта |
| `02-wizard/` | Мастер из трёх шагов + отдельный экран очереди |
| `03-autopilot/` | Панель поверх страницы с «умными» умолчаниями и слежением за сериями |

Каждый прототип — ровно три файла: `index.html`, `styles.css`, `app.js`.

## Что дальше

Владелец выбирает вариант → он переносится в `client-extension/` (с реальным API,
`chrome.scripting` и т.д.) → эта папка удаляется целиком.

Ориентир: `01-reskin` — это тот же попап, что и сейчас, поэтому его перенос почти
бесплатный (визуальная часть уже подготовлена в `client-extension/popup.css`).
`02` и `03` требуют перестройки `popup.js` (для `03` — вообще новый content script).
