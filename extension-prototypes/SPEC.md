# SPEC — общее ТЗ прототипов расширения

> **Итог:** выбран вариант `01-reskin`; его логика уже в `client-extension/` (0.7.0)
> вместе с тремя правками по фидбеку (ручной выбор серий, «Только субтитры»,
> сворачиваемая очередь). `02` и `03` — история, переносить не нужно.

Все три прототипа показывают **один и тот же продукт** — попап расширения
«HDrezka → Сервер» в дизайне сайта. Совпадают: палитра, типографика, компоненты,
мок-данные и симуляция. Отличается **логика** — см. раздел «Чем отличаются варианты».

## Технические ограничения

- Ровно три файла в папке прототипа: `index.html`, `styles.css`, `app.js`.
- Чистый vanilla JS, обычный скрипт (не модуль), код проходит `node --check`.
- Никаких внешних ресурсов: без CDN, без шрифтов, без картинок. Иконки — inline SVG,
  «постеры»/аватары — CSS-градиенты.
- Работает и через `file://`, и через статический HTTP-сервер.
- **border-radius: 0 везде.**
- Язык интерфейса — русский.
- Стиль — как у `server/public/styles.css`: те же CSS-переменные
  (`--bg: #f5f6f8`, `--card: #fff`, `--border: #e2e5ea`, `--accent: #2563eb`,
  `--ok: #16a34a`, `--err: #dc2626`, `--warn: #d97706`), карточки в рамке с мягкой
  тенью, пилюли статусов, 5-пиксельные полосы прогресса, системные шрифты,
  `--font-variant-numeric: tabular-nums` для чисел.
- В интерфейсе видна плашка «Прототип №N — данные ненастоящие».

## Общее поведение (одинаковое во всех прототипах)

- Тик раз в секунду: «Скачивается» прибавляет 4–12 МБ/с с джиттером; прогресс, мегабайты
  и скорость обновляются. Когда задача готова — уходит в «Готово» (счётчики растут).
- Одновременно качается не более 3 задач; освободился слот — стартует первая из очереди.
- «Оппенгеймер» остаётся в ошибке, пока не нажмут «Повторить».
- Действия: пауза, продолжить, отменить, повторить, удалить; «Остановить все» /
  «Возобновить все» / «Повторить сбойные» — по наличию подходящих задач.
- Деструктивные действия (отмена, остановить все, удалить) подтверждаются вторым
  кликом: первый клик меняет надпись на «Точно …?» примерно на 4 секунды.
- Отправка на сервер («Скачать…») добавляет задачи в начало очереди со статусом
  «В очереди», показывает тост «Отправлено: N задач» и короткий статус.
- Ошибка связи с сервером симулируется переключателем в демо-баре: виджет сервера
  краснеет, в очереди появляется полоса «Нет связи», кнопка отправки сообщает об ошибке.
- Состояние «не та страница» (открыт не фильм/сериал) симулируется там же.

## Чем отличаются варианты

### 01-reskin — «тот же попап, новый вид»

Логика 1:1 как в текущем расширении: одна вертикальная простыня (настройки → страница →
озвучка/качество/субтитры/диапазон → большая кнопка → очередь внизу), все выборы —
нативные `<select>`, диапазон серий — четыре зависимых селекта, экран один.

Отличие от `02`/`03`: ничего не перестроено, меняется только внешний вид.

### 02-wizard — «мастер»

- Верх — сегмент-переключатель **«Загрузка | Очередь»**: это два отдельных экрана,
  а не одна прокрутка.
- Загрузка — мастер из трёх шагов с индикатором: **1 Что качать → 2 Параметры →
  3 Проверить и отправить**. Вперёд без выбранных серий не пускает, назад — свободно.
- Шаг 1: пресеты «Текущая серия / Сезон / Весь сериал / Выбрать» и **сетка чипов серий**
  (клик — вкл/выкл, «Выбрать все» / «Снять») вместо четырёх селектов. Живая сводка
  «Выбрано: N серий · ≈ X GB».
- Шаг 2: озвучка и качество — **радио-карточки** с бейджами (премиум ★, ≈ размер),
  субтитры — чипы языков.
- Шаг 3: сводка отправки (файл, качество, размер), предупреждение «уже скачивалось»,
  строка сервера и кнопка «Отправить N задач».
- Экран «Очередь»: фильтры «Все / Активные / Ошибки / Готовые», карточки сгруппированы
  по фильму: прогресс группы, действия группы (пауза/отмена/повторить/удалить),
  разворачиваемый список файлов.

### 03-autopilot — «автопилот»

Маленькая связь с прошлым: **попапа нет**.

- Расширение работает как панель, закреплённая поверх страницы (эмулирует content
  script / side panel). Панель видна на фоне настоящей страницы (макет страницы
  hdrezka нарисован в прототипе).
- Никаких форм: панель **уже знает** страницу, озвучку и качество («умные умолчания»).
  Главное действие — **одна кнопка «Скачать серию»**; рядом «Сезон целиком».
- Умолчания меняются чипами прямо в панели (качество, субтитры) — без перехода в
  настройки; полные настройки (адрес сервера, токен, дефолты) — в шторке по шестерёнке.
- **Режим сериала:** «Сезон целиком» ставит серии по порядку и показывает
  «Отправлено N из M» — можно остановить.
- **Автопилот:** тумблер «Следить за новыми сериями». Включён — через ~15 секунд
  симуляция «находит» S01E03 и сама ставит её в очередь (тост + запись в журнале).
- Панель **сворачивается в пилюлю** в углу («⤓ 2 · 63%»), когда не нужна, —
  это монитор, а не диалог.
- Внизу — живой список задач сервера (компактный) и кнопка «Открыть сервер» (мок).
